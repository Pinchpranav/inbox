Q: How has the journey been picking up tickets and building? Any changes/things noticed that could be improved?
A: Smooth overall — the proven-files invariant + reviewer + live verification kept the backend solid and the milestone actually works end-to-end. Main friction: (1) build-5ei's spec was internally inconsistent (async manager vs sync buildApp) forcing a justified deviation; (2) build-n9b and build-2c9 were coupled in code (deleting gatewayClient broke chat) so they had to be done together despite being separate tickets; (3) the reviewer agent had no shell tool so it couldn't run tsc itself and hit a .d.ts/.d.mts path typo; (4) bd ready returned empty because all beads were dependency-blocked, so the "next actionable" bead had to be traced manually; (5) dev hygiene — leftover processes caused EADDRINUSE, and the backend doesn't mkdir its DB dir; (6) POST /api/projects requires a dir, surfacing as an awkward absolute-path prompt in the UI.
